# Sword Fern Studio Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Evergreen site on the `sword-fern-studio` branch as the Sword Fern Studio field-guide page described in the spec.

**Architecture:** One Astro page made of one component per section, all copy and image slots read from typed exports in `src/content/site.ts`. Plain CSS, with tokens in `global.css` and scoped styles per component. Tests are `node:test` files that read the built `dist/index.html` and CSS, so they check what visitors actually get.

**Tech Stack:** Astro 7, TypeScript, plain CSS, Fontsource (`@fontsource/im-fell-english`, `@fontsource-variable/literata`, `@fontsource-variable/caveat`), `sharp` (already installed through Astro) for the OG image, `node:test` (no new test deps).

**Spec:** `docs/superpowers/specs/2026-11-04-sword-fern-studio-design.md`. The approved mockup linked there is the visual reference; its CSS tokens may be copied.

## Global Constraints

- After the build, `git grep -i evergreen -- ':!docs'` returns nothing.
- `<title>`: `Sword Fern Studio — software, made by hand on Vancouver Island`.
- Fonts: IM Fell English (headings), Literata (body), Caveat (annotations only, never essential info). Self-hosted via Fontsource.
- Palette tokens: fern green, ink black-brown, warm paper, mushroom orange accent. Dark mode via `prefers-color-scheme`.
- Copy is placeholder. Anything Carly writes renders as `[Carly writes: …]`. The "Made by hand, with help" body must not be drafted.
- Exactly one strikethrough on the page (Plate II note). No coffee ring, stains or smudges.
- The page works fully with JS off. No content starts at `opacity: 0` unless `html.js` is set.
- All motion is disabled under `prefers-reduced-motion: reduce`.
- Email only via `mailto:`. No forms.
- Node ≥ 22.12 (`.nvmrc`). No new runtime dependencies beyond the three font packages.

## Review Focus

1. **Phone width (360px):** tilted and offset sheets must not cause horizontal scroll. Expect straight, full-width sheets below 600px and `overflow-x: clip` on the page wrapper. (Task 4 test, plus manual check in Task 7.)
2. **JS off / slow JS:** every section is visible. Fade-in hidden states are scoped under `html.js`. (Task 6 test.)
3. **Keyboard-only:** the fern easter egg is reachable by Tab and reveals its note on focus, and every key link lands on an element with a matching `id`. (Task 3 and Task 4 tests.)
4. **Missing image files:** a slot whose `src` is empty renders the dashed placeholder, never a broken `<img>`. (Task 3 test.)
5. **No email yet:** with `contact.email === ''` the page shows the `[email goes here]` placeholder, there is no `mailto:` link, and LinkedIn is the primary link. (Task 5 test.)
